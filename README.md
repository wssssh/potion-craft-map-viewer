# Potion Craft 完整药剂地图

基础 React + Vite + Canvas 实现的独立静态地图查看器。网页所需的已提取地图素材位于 public/data/，运行网页不需要读取游戏安装文件或存档。

## 启动

在此目录执行：

```powershell
npm install
npm run dev
```

打开 http://127.0.0.1:5174/ 。生产静态文件可通过 `npm run build` 生成，再运行 `npm run preview`。

## 使用

- 水、油、酒地图切换；水有 41 个效果，油、酒各 21 个。
- 滚轮围绕鼠标位置缩放，拖拽移动，双击放大。
- 搜索中文或英文药剂名，点击列表定位；点击地图中的效果点查看坐标和旋转角度。
- 右上角支持放大、缩小、查看全图、回到起点。
- 地图聚焦后可使用方向键移动、加减键缩放、`0` 查看全图。
- 药剂名称、漩涡与出口、经验书图层可切换；小屏幕通过“药剂列表”打开侧栏。
- 漩涡与对应出口使用棕色弯曲虚线连接，沿用游戏原始曲线路径，随地图缩放移动，并由“漩涡与出口”图层控制显示。水基底有 80 条，油基底有 19 条，酒基底场景没有此类路径。
- 地图药剂使用原始瓶形与棕色轮廓，图标和小标签均按地图比例缩放。小标签使用游戏 Noto Serif SC 中文字体及原始按钮底纹，点击标签也可选中药剂；文字小于 5.5 像素时自动隐藏。
- 全页采用游戏风格：羊皮纸面板、棕色衬线字体、墨线边框和原始按钮轮廓。基底图标、加减、关闭、勾选框使用提取的游戏素材，列表、搜索、图层、详情和手机侧栏使用统一样式。

## 资源与验证

地图来自游戏的 `level6`、`level7`、`level8` 场景及其引用的 Unity 精灵素材。场景中的所有地图地形元素按原始层级变换、位置、缩放和旋转还原；探索迷雾被排除。

网页使用 512 × 512 的无损 WebP 分块及多级分辨率，按可见区域请求图片。最高分辨率为 100 像素 / 游戏坐标单位，保留主要地图素材的原始像素密度；不会一次加载整张巨型图片。网页不包含 PNG 地图导出。

药剂图标由游戏的原始颜色层、轮廓层和划痕层合成。纸张背景为游戏纹理。浏览器的合成方式与 Unity 的动态着色器、动画可能有视觉差异，这是静态地图查看器。中文名称是便于查询的对照标签，英文 ID 为游戏原始标识。

全部 83 个效果实例的坐标、旋转已与游戏 `PotionBase` 配置核对；坐标误差小于 0.000002 个游戏单位。2207 个地图分块及叠加素材文件均检查存在，结果在 `public/data/validation.json`。

原项目浏览器验证记录：桌面 1440 × 1000、手机 390 × 844；地图切换、搜索定位、滚轮缩放、拖拽、放大缩小、图层切换和手机侧栏均通过。初始 React 导入问题已修复。未测试实际触屏设备的双指操作。2026-10-09 搬迁后重新验证了构建。

## 重新提取

本公开仓库只包含独立查看器及浏览所需素材，UnityPy 提取工具由私有主仓库单独维护，不包含在此仓库中。

地图和字体等游戏素材归原权利人所有。本仓库未为第三方游戏素材授予额外许可。游戏版本变化后需要重新提取并核对地图数据。
